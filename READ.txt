при каждом обновлении лаунчера (при новом билде) версия менялась в зависимости от новых функций и исправлений.

Формат версии: MAJOR.MINOR.PATCH

- Новая функция → MINOR +1, PATCH = 0 (например 1.8.18 → 1.9.0)
- Еще одна новая функция → MINOR +1 (1.9.0 → 1.10.0)
- Исправление → PATCH +1 (1.9.0 → 1.9.1)
- Еще одно исправление → PATCH +1 (1.9.1 → 1.9.2)

ВАЖНО: После каждого изменения (функции или исправления) нужно:
1. Обновить CHANGELOG.md
2. Обновить версию в package.json
3. Запустить typecheck (npm run typecheck)
4. Сделать билд EXE (npm run build && npx electron-builder --win)
