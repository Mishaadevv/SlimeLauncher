# SlimeLauncher Skin Directory

Мини-сервер, который делает скины видимыми между двумя игроками SlimeLauncher
**на любом стороннем сервере** через интернет (без общего LAN и без
Network-таба).

## Как это работает

1. Лаунчер при смене скина и при каждом запуске игры публикует свой скин:
   `PUT /api/skins/<ник>`.
2. Когда игра запрашивает профиль другого игрока, локальный skin server
   лаунчера сначала ищет скин в своих источниках (свои данные, друзья по LAN,
   Network-пиры), а если не нашёл — спрашивает каталог по offline-UUID игрока.
   Offline-UUID детерминированно вычисляется из ника
   (`md5("OfflinePlayer:<ник>")`), поэтому поиск по UUID однозначно находит
   нужную запись.
3. Найденный скин кэшируется локально на 24 часа.

## Запуск

Нужен только Node.js 18+:

```bash
node server.mjs              # порт 8080
PORT=9000 node server.mjs    # свой порт
```

Данные хранятся в `data.json` рядом со скриптом (атомарная запись).
Для продакшена поставьте за nginx/caddy с TLS и укажите публичный URL в
настройках лаунчера: **Settings → Advanced → Skin directory URL**.

## API

| Метод | Путь | Описание |
|-------|------|----------|
| PUT | `/api/skins/<nick>` | `{ skin: base64png, variant, cape? }` — опубликовать скин |
| GET | `/api/skins/<nick>` | скин по нику |
| GET | `/api/skins/byuuid/<uuid32>` | скин по offline-UUID |
| GET | `/health` | проверка живости |

Ограничения: PNG до 8 МБ, 10 публикаций в минуту с одного IP.

## Важно про доверие

В v1 нет аутентификации: любой, кто знает ник, может перезаписать его скин
(last write wins). Для каталога «для своих» это приемлемо. Перед публичным
запуском добавьте per-nick токены (выдавать секрет при первой публикации и
требовать его при обновлении).
